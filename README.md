# Готельний комплекс «Гала Готель»

Live site: https://gala.hotelup.work

## About
«Гала Готель» — 3★ готельний комплекс на 68 номерів у Кам’янці-Подільському, вул. Лесі Українки, 84. Сторінка побудована за формулою STAY · DINE · PLAY · MEET: проживання, ресторан «Пуаро» з українською, європейською та середземноморською кухнею, безкоштовний сніданок, боулінг, сауна, тенісний корт, конференц-зал, групові поїздки та екскурсійне обслуговування.

## Amenities
- 68 номерів, кондиціонування, кухня в частині номерів, безкоштовний доступ до інтернету
- Безкоштовний сніданок, ресторан «Пуаро», бар
- Боулінг, сауна, тенісний корт, дитячий майданчик
- Конференц-зал, екскурсійне обслуговування
- Приватний паркінг, pet-friendly, трансфер до/з аеропорту (умови уточнюються)
- Заїзд 14:00, виїзд 12:00

## Forms
Live forms send requests to HotelOS (hotelId `kp-gala`): `stay-request` (also used for group trips), `sauna-request`, `conference-request`. Phone is the only required field. The old Telegram request form was replaced; bowling, tennis and excursion CTAs go to the phone.
